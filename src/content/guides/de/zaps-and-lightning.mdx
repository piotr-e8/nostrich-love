## Was sind Zaps? ⚡

Zaps sind Bitcoin-Trinkgelder, die über das Lightning Network gesendet werden. Sie sind die native Wertschicht von Nostr—sie ermöglichen es Nutzern, Inhalte, die sie lieben, mit echtem Geld zu belohnen.

Denk an sie als "Likes mit Wert"—eine Art, Menschen zu unterstützen, deren Inhalte du genießt.

### Wie Zaps Funktionieren

1. **Du erstellst guten Content** → Ein Post, Thread oder Antwort
2. **Jemand genießt ihn** → Sie klicken den ⚡ Zap-Button
3. **Sie senden Satoshis** → Winzige Mengen Bitcoin (1000 Sats = ~0,30$)
4. **Du empfängst sofort** → Geld erscheint in deinem Wallet
5. **Jeder sieht es** → Zaps sind öffentlich und erzeugen Social Proof

### Warum Zaps Revolutionär Sind

**Traditionelle Soziale Medien:**

- Likes sind kostenlos und wertlos
- Plattform behält alle Werbeeinnahmen
- Creators bekommen nichts
- Engagement ist hohl

**Nostr mit Zaps:**

- Jeder Like kann echten Wert haben
- Keine Plattform nimmt einen Cut
- Direkte Creator-Unterstützung
- Bedeutungsvolles Engagement

### Echte Beispiele

- Entwickler erhält 100.000 Sats (30$) für Bug-Fix
- Künstler wird gezappt für das Teilen ihrer Arbeit
- Autor verdient Bitcoin für aufschlussreiche Threads
- Meme-Creator bekommt Trinkgelder für viralen Content

### Das Value-for-Value Modell

```
Traditionelle Soziale Medien:       Nostr:
┌──────────────────┐                 ┌──────────────────┐
│ Kostenlos posten │                 │ Kostenlos posten │
│ Kostenlos lesen  │                 │ Kostenlos lesen  │
│ Attention = $$$  │                 │ Attention = ⚡   │
│ (für Plattform)  │                 │ (für Creator)    │
└──────────────────┘                 └──────────────────┘
```

### Wie Zaps Erscheinen

In unterstützten Clients zeigen sich Zaps als:

- ⚡ Lightning-Blitz-Symbole
- Gezappte Menge (z.B. "21 Sats")
- Laufende Summen auf Posts
- Spezielle Benachrichtigungen, wenn du sie empfängst

```
┌────────────────────────────────────┐
│ Alice                              │
│ "Habe gerade meinen neuen Artikel  │
│  veröffentlicht!"                  │
│ [❤️ 12] [💬 3] [⚡ 5.420 Sats]     │
│                                    │
│ ⚡ Bob zappte 1.000 Sats           │
│ ⚡ Carol zappte 500 Sats           │
└────────────────────────────────────┘
```

### Nicht Erforderlich!

> 💡 **Wichtig**: Zaps sind komplett optional. Du kannst Nostr für immer kostenlos nutzen, ohne jemals einen einzigen Satoshi zu senden oder zu empfangen.

## Wallet Einrichtung 💼

Bevor du Zaps senden oder empfangen kannst, brauchst du ein Lightning Wallet.

### Empfohlene Wallets

#### Für Anfänger

**Alby** (Browser Extension)

- Einfache Einrichtung
- Großartige Nostr-Integration
- Funktioniert in Web-Clients
- [getalby.com](https://getalby.com)

**Phoenix** (Mobile)

- Benutzerfreundlich
- Self-custodial
- iOS und Android
- [phoenix.acinq.co](https://phoenix.acinq.co)

#### Für Fortgeschrittene Nutzer

**Zeus** (Mobile)

- Verbinde dich mit deiner eigenen Node
- Volle Kontrolle
- Power-User Features
- [zeusln.app](https://zeusln.app)

**Mutiny** (Web/Mobile)

- Self-custodial im Browser
- Kein App Store nötig
- [app.mutinywallet.com](https://app.mutinywallet.com)

### Custodial vs Non-Custodial

**Custodial (Alby, Wallet of Satoshi)**

- ✅ Einfache Einrichtung
- ✅ Niedrigere Gebühren
- ❌ Sie halten deine Mittel
- ❌ KYC kann erforderlich sein

**Non-Custodial (Phoenix, Zeus, Mutiny)**

- ✅ Du kontrollierst deine Schlüssel
- ✅ Bessere Privatsphäre
- ❌ Etwas komplexer
- ❌ Höhere On-Chain Gebühren

> 💡 **Empfehlung**: Starte mit Alby für Web-Nutzung + Phoenix für Mobile. Upgrade auf Non-Custodial, wenn du dich wohl fühlst.

### Option 3: Wallet of Satoshi (Am Einfachsten)

**Am besten für:** Komplette Anfänger, die Einfachheit wollen

**Vorteile:**

- Keine Einrichtung erforderlich
- Einfach herunterladen und loslegen
- Lightning Address inklusive
- Funktioniert sofort

**Nachteile:**

- Not your keys, not your coins
- Erfordert Vertrauen in Anbieter
- Limits bei Abhebungen

**Plattform:** iOS, Android

### Dein Wallet Verbinden

#### Schritt-für-Schritt: Alby + Web Client

1. **Installiere Alby Extension**
   - Chrome/Firefox: [getalby.com](https://getalby.com)
   - Erstelle Account oder nutze existierenden

2. **Hol Dir Deinen Connection String**
   - Alby Dashboard → API Keys
   - Oder: Profil → Nostr Wallet Connect

3. **Mit Client Verbinden**
   - In deinem Nostr Client (Primal, Iris, etc.)
   - Einstellungen → Wallet → Verbinden
   - Connection String einfügen

4. **Teste mit Einem Kleinen Zap**
   - Finde einen Post, den du magst
   - Klicke ⚡ Button
   - Sende 10 Sats

#### Schritt-für-Schritt: Phoenix + Mobile Client

1. **Lade Phoenix Herunter**
   - App Store / Play Store
   - Erstelle Wallet (sichere Seed-Phrase!)

2. **Lade Dein Wallet Auf**
   - Kaufe Bitcoin oder empfange von woanders
   - Brauchst mindestens 10.000 Sats zum Starten

3. **Hol Dir LNURL oder Lightning Address**
   - Phoenix → Empfangen → Lightning Address
   - Kopiere `deinname@phoenix.wallet` oder LNURL

4. **Füge zu Nostr Profil Hinzu**
   - Client → Profil → Bearbeiten
   - Lightning Address einfügen

#### Schritt-für-Schritt: Wallet of Satoshi + Mobile Client

1. **Lade Wallet of Satoshi Herunter**
   - Gehe zum App Store (iOS/Android)
   - Suche "Wallet of Satoshi"
   - Herunterladen und installieren
   - Öffne die App (kein Account nötig!)

2. **Hol Dir Deine Lightning Address**
   - Tippe "Empfangen"
   - Suche nach deiner Lightning Address
   - Sieht so aus: `benutzername@walletofsatoshi.com`
   - Schreib dies auf—du wirst es brauchen

3. **Füge zu Deinem Nostr Profil Hinzu**
   - Öffne deinen Nostr Client (Damus, Amethyst, Iris, etc.)
   - Gehe zu Profil Bearbeiten
   - Finde "Lightning Address" oder "LN Address" Feld
   - Füge deine Adresse ein
   - Speichere Änderungen

4. **Verifiziere, Dass Es Funktioniert**
   - Suche nach ⚡ Symbol auf deinem Profil
   - Bitte einen Freund, dir einen Test-Zap zu senden (100 Sats)
   - Prüfe dein Wallet—solltest sofort empfangen
   - Du solltest eine Zap-Benachrichtigung in deinem Client sehen

<Callout type="warning">
  **Wichtig:** Schreib deine Wallet-Recovery-Phrase auf, wenn du Phoenix nutzt! Wenn du den Zugriff auf dein Wallet verlierst, verlierst du dein Bitcoin. Keine Ausnahmen.
</Callout>

## Zaps Senden 💸

### Wie Man Einen Post Zappt

1. **Finde einen Post, den du magst**
2. **Tippe den ⚡ Button**
3. **Wähle Betrag** oder gib benutzerdefinierten ein
4. **Füge Nachricht hinzu** (optional)
5. **Bestätige** und sende!

### Zap-Beträge Etikette

**Schnellreferenz:**

| Betrag           | Wann zu Nutzen                  |
| ---------------- | ------------------------------- |
| 10-50 Sats       | Kleine Wertschätzung            |
| 100-500 Sats     | Guter Post/Thread               |
| 1.000-5.000 Sats | Großartiger Content, Podcast    |
| 10.000+ Sats     | Außergewöhnlicher Wert, Kunst   |

> 💡 **Faustregel**: Zappe, was der Content für dich wert ist. Kein Betrag ist zu klein!

### Benutzerdefinierte Nachrichten

Die meisten Clients erlauben es dir, eine Nachricht zu deinem Zap hinzuzufügen:

```
"Danke für die Hilfe!"
"Toller Thread, viel gelernt"
"☕ Kaffee geht auf mich"
```

Das personalisiert die Interaktion und hilft Creators zu verstehen, welcher Content ankommt.

## Zaps Empfangen 💰

### LNURL Einrichten

Um Zaps zu empfangen, musst du konfigurieren, wohin sie gehen:

1. **Hol Dir Deine Lightning Address oder LNURL**
   - Von deinem Wallet (Alby, Phoenix, etc.)
   - Format: `deinname@provider.com`

2. **Füge zu Deinem Profil Hinzu**

   ```
   Client → Profil → Bearbeiten → Lightning Address
   Einfügen: deinname@getalby.com
   ```

3. **Verifiziere, dass es funktioniert**
   - Bitte einen Freund, dir 10 Sats zu senden
   - Oder nutze ein Testnet Faucet

### Zap-Benachrichtigungen

**In den meisten Clients:**

- Push-Benachrichtigung wenn gezappt
- Benachrichtigungs-Tab zeigt Zap-Historie
- Kannst sehen, wer dich gezappt hat

**Datenschutz-Hinweis:**
Zaps sind semi-öffentlich. Während Beträge in manchen Setups privat sein können, ist die Tatsache, dass du gezappt hast (oder gezappt wurdest) sichtbar.

## Zap Splits [ADVANCED]

<Note type="advanced">
  Optionales Feature zum automatischen Teilen von Zap-Einnahmen.
</Note>

### Was sind Zap Splits?

Wenn jemand deinen Post zappt, teile die Zahlung automatisch mit Mitarbeitern:

```
Beispiel: Podcast-Episode
├── 70% → Host (du)
├── 20% → Producer
└── 10% → Editor
```

### Splits Einrichten

1. **In deinem Client**: Suche nach "Zap Splits" oder "Recipients"
2. **Mitarbeiter hinzufügen**: Gib ihre Lightning Addresses ein
3. **Prozentsätze festlegen**: Muss insgesamt 100% ergeben
4. **Speichern**: Zukünftige Zaps werden automatisch geteilt

### Häufige Anwendungsfälle

- **Podcasts**: Teilen zwischen Host und Gästen
- **Kollaborative Posts**: Teilen mit Co-Autoren
- **Kunst**: Teilen mit Inspirationsquellen
- **Open Source**: Dependencies finanzieren

## Creator Best Practices

### Zap-Unterstützung Maximieren

**1. Schaffe Wert**

- Bildungsinhalte
- Einzigartige Einblicke
- Unterhaltung
- Hilfreiche Tools/Ressourcen

**2. Sei Konsistent**

- Poste regelmäßig
- Baue Vertrauen über Zeit auf
- Qualität über Quantität

**3. Würdige Unterstützer**

- Danke Leuten, die zappen
- Antworte auf Kommentare
- Baue Beziehungen auf

**4. Signalisiere Wert**

- "Zaps willkommen" gelegentlich
- Zeige Wertschätzung
- Bettle oder fordere nicht

**5. Diversifiziere Einkommen**

- Verlasse dich nicht nur auf Zaps
- Biete bezahlte Inhalte/Abonnements an
- Baue Produkte/Services
- Akzeptiere direkte Spenden

### Steuerliche Überlegungen

<Callout type="warning">
  **Keine Finanzberatung.** Konsultiere einen Steuerexperten in deinem Land.
</Callout>

**Allgemeine Prinzipien:**

- Zaps können steuerpflichtiges Einkommen sein
- Führe Aufzeichnungen über Einnahmen
- Umwandlung in Fiat = steuerpflichtiges Ereignis in den meisten Ländern
- Gehaltenes Bitcoin = Kapitalgewinne beim Verkauf

**Tools:**

- Koinly, CoinTracker für Tracking
- Exportiere Wallet-Historie regelmäßig
- Dokumentiere alles

## Zaps Fehlerbehebung 🔧

### "Zap-Button funktioniert nicht"

- Prüfe, ob Wallet verbunden ist (Einstellungen → Wallet)
- Stelle sicher, dass du ausreichend Guthaben hast
- Versuche den Client neu zu laden

### "Wallet verbindet sich nicht"

- Verifiziere, dass dein Connection String korrekt ist
- Prüfe, dass dein Wallet entsperrt ist
- Manche Wallets müssen "online" sein (Phoenix)

### "Zaps erscheinen nicht"

- Zaps brauchen ein paar Sekunden zur Verarbeitung
- Manche Clients bündeln Benachrichtigungen
- Prüfe dein Wallet direkt zur Bestätigung

### "Kann keine Zaps empfangen"

- Verifiziere, dass deine Lightning Address in deinem Profil ist
- Teste zuerst mit einem kleinen Betrag
- Stelle sicher, dass dein Wallet läuft (non-custodial)

- ❌ Erwarte Zaps im Gegenzug

- ❌ Vergiss nicht, deine Wallet-Seed zu sichern
