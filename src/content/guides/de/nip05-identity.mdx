## Was ist NIP-05? 🆔

NIP-05 (Nostr Implementation Possibility #5) ermöglicht dir eine menschenlesbare Identifikation wie `du@domain.com` statt einer langen Zeichenkette aus zufälligen Zeichen.

### Das Problem, Das Es Löst

```
Vor NIP-05:
┌──────────────────────────────────────────────┐
│ Follow: npub1xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx  │
│ "Hey, folge mir! Ich bin npub1abc123...xyz789"│
└──────────────────────────────────────────────┘
                ↓
Nach NIP-05:
┌──────────────────────────────────────────────┐
│ Follow: alice@example.com                    │
│ "Hey, folge mir! Ich bin alice@example.com"  │
└──────────────────────────────────────────────┘
```

### Was Du Bekommst

- ✅ **Einfach zu teilen**: "Finde mich unter bob@nostrplebs.com"
- ✅ **Sieht professionell aus**: Saubere, einprägsame Identifikation
- ✅ **Vertrauenssignal**: NIP-05 Badge in vielen Clients
- ✅ **Leichter zu finden**: Suche nach deiner Identifikation

### Aber Denk Dran...

> ⚠️ **NIP-05 ist optional.** Du kannst Nostr perfekt mit nur deinem npub nutzen.

Die NIP-05 Identifikation ist eine **Bequemlichkeit**, keine Anforderung. Dein `npub` ist deine echte Identität auf Nostr.

---

## Warum NIP-05 Verwenden? ✨

### Einfacher zu Teilen

```
Auf einer Party:
"Was ist dein Nostr?"

Ohne NIP-05:
"Äh... n-p-u-b-eins-x-x-x... lass mich auf meinem Handy suchen"

Mit NIP-05:
"Einfach alice@example.com"
```

### Professionelles Erscheinungsbild

- **Unternehmen**: `support@yourcompany.com`
- **Kreative**: `artist@yourdomain.com`
- **Entwickler**: `dev@opensourceproject.com`

### Vertrauen & Authentizität

Viele Clients zeigen ein ✓ Badge für NIP-05 Nutzer:

```
┌─────────────────────┐
│ 👤 Alice ✓          │
│ alice@example.com   │
│ "Bitcoin Educator"  │
└─────────────────────┘
```

Das hilft Menschen zu wissen, dass sie dem echten dir folgen, nicht einem Betrüger.

### Brauchst Du Eines?

**Nein.** Du kannst Nostr perfekt ohne es nutzen.

**Aber...** es ist sehr empfehlenswert, wenn du:

- Eine persönliche Marke aufbaust
- Inhalte erstellst
- Ein Unternehmen führst
- Nostr langfristig ernst nimmst
- Es leid bist, 63-Zeichen-Zeichenketten zu lesen

### Keine Zentralisierung!

Manche befürchten, NIP-05 bedeute "zentralisierte Identität". Das tut es nicht:

- Du kannst **mehrere** NIP-05 Identifikationen haben
- Du kannst sie **jederzeit ändern**
- Dein **npub** ist immer noch deine echte Identität
- NIP-05 ist nur ein **Zeiger** auf deinen npub

## Deine Eigene Domain Verwenden 🌐

Für vollständige Kontrolle und Professionalität nutze deine eigene Domain.

### Schritt 1: Kaufe eine Domain

Jeder Domain-Registrar funktioniert:

- [Namecheap](https://namecheap.com)
- [Porkbun](https://porkbun.com)
- [Cloudflare Registrar](https://www.cloudflare.com/products/registrar/)

Kosten: Normalerweise 10-15$/Jahr

### Schritt 2: Erstelle die nostr.json-Datei

Hoste eine Datei unter `https://deinedomain.com/.well-known/nostr.json`:

```json
{
  "names": {
    "alice": "b0635d6a9851d3aed0cd6c495b282167acf761729078d975fc341b22650b07b9"
  }
}
```

<Callout variant="warning" title="Verwende deinen öffentlichen Schlüssel als Hex, nicht deinen npub">
  NIP-05 erwartet deinen öffentlichen Schlüssel als reines Kleinbuchstaben-Hex.
  Wenn du `npub1...` in `nostr.json` einträgst, schlägt die Verifizierung bei
  allen Clients fehl — und zwar stillschweigend, ohne Fehlermeldung.

Die meisten Clients zeigen die Hex-Form unter Einstellungen → Schlüssel als
"public key (hex)". Du kannst deinen npub auch in das Prüfwerkzeug weiter unten
auf dieser Seite einfügen, das beide Formen nebeneinander anzeigt.

</Callout>

**Es sind keinerlei DNS-Einträge beteiligt.** Die NIP-05-Verifizierung ist eine
gewöhnliche HTTPS-Anfrage an `/.well-known/nostr.json`. Du brauchst weder einen
TXT-Eintrag noch einen CNAME noch sonst einen DNS-Eintrag über den hinaus, der
deine Domain bereits auf deinen Webserver zeigen lässt.

Deine Identifikation wird: `alice@deinedomain.com`

### Beispiel Setup Durchlauf

**Szenario:** Du besitzt `alice.dev`

1. **Erstelle die JSON-Datei:**

```json
{
  "names": {
    "alice": "b0635d6a9851d3aed0cd6c495b282167acf761729078d975fc341b22650b07b9"
  }
}
```

2. **Lade sie auf deinen Server hoch:**

```
https://alice.dev/.well-known/nostr.json
```

3. **Überprüfe, ob es funktioniert:**
   Öffne im Browser: `https://alice.dev/.well-known/nostr.json`

4. **Füge es deinem Nostr-Profil hinzu:**
   In deinem Client: Einstellungen → Profil → NIP-05 → `alice@alice.dev`

## Teste Dein NIP-05 ✅

### Überprüfe Deine Identifikation

Nutze unser Tool unten oder besuche deine Identifikations-URL:

<NIP05Checker showForm={true} client:idle />

### In Deinem Client

Die meisten Clients zeigen den NIP-05 Status:

**Damus/Amethyst:**

- Einstellungen → Profil → NIP-05 Feld
- Zeigt ✓ wenn korrekt eingerichtet

**Primal:**

- Profil zeigt NIP-05 Badge
- Klicke Badge für Details

### Häufige Probleme Beheben

**"NIP-05 funktioniert nicht"**

- Überprüfe, ob dein npub in nostr.json korrekt ist
- Stelle sicher, dass das JSON valide ist (nutze einen JSON-Validator)
- Prüfe, dass die Datei unter der exakten URL erreichbar ist

**"Datei nicht gefunden"**

- Stelle sicher, dass der `.well-known` Ordner erstellt ist
- Prüfe, ob dein Server versteckte Verzeichnisse ausliefert
- Verifiziere den Pfad: `/.well-known/nostr.json`

**"Domain löst nicht auf"**

- DNS-Änderungen können bis zu 24 Stunden dauern
- Lösche deinen DNS-Cache
- Prüfe mit `dig` oder `nslookup` Befehl

**"Client erkennt es nicht"**

- Manche Clients cachen NIP-05 Lookup-Ergebnisse
- Versuche dich aus- und wieder einzuloggen
- Warte ein paar Minuten für die Propagierung

**"Verification Failed" Fehler**

**Mögliche Ursachen:**

1. **JSON Syntaxfehler** - Prüfe auf fehlende Anführungszeichen oder Kommas
2. **Falscher Dateipfad** - Muss unter `/.well-known/nostr.json` sein
3. **Caching** - Warte 10-15 Minuten und versuche es erneut
4. **HTTPS erforderlich** - Muss über HTTPS ausgeliefert werden

**Lösung:**

- Validiere JSON auf jsonlint.com
- Prüfe, ob die Datei am exakten Pfad ist
- Lösche Client-Cache
- Stelle sicher, dass das SSL-Zertifikat gültig ist

**"Not Found" Fehler**

**Mögliche Ursachen:**

1. Datei nicht am korrekten Ort hochgeladen
2. Server blockiert Punkt-Verzeichnisse
3. Falsche Domain

**Lösung:**

- Verifiziere, dass die Datei unter der exakten URL existiert
- Prüfe `.htaccess` oder Server-Config erlaubt Punkt-Verzeichnisse
- Bestätige, dass du die richtige Domain verwendest

**Anbieter-Spezifische Probleme**

**NostrPlebs:**

- Prüfe Spam-Ordner für Verifizierungs-E-Mail
- Stelle sicher, dass npub korrekt ist (nicht nsec!)
- Kontaktiere Support falls du feststeckst

**Self-hosted:**

- Verifiziere DNS-Propagierung: `dig deinedomain.com`
- Prüfe Server-Logs auf Fehler
- Stelle sicher, dass Dateiberechtigungen Lesen erlauben

<Callout variant="warning">
  Teile niemals deinen nsec (privaten Schlüssel) beim Einrichten von NIP-05. Nur dein npub
  (öffentlicher Schlüssel) wird benötigt.
</Callout>

## Fortgeschrittene Tipps 💡

### Mehrere Identitäten

Du kannst mehrere NIP-05 Adressen haben:

```
persoenlich@deinedomain.com
arbeit@deinedomain.com
blog@deinedomain.com
```

Alle zeigen auf denselben npub, oder verschiedene.

### Subdomains

Nutze Subdomains zur Organisation:

```
alice@team.deinedomain.com
alice@community.deinedomain.com
```

### Mehrere Nutzer Hosten

Du kannst mehrere NIP-05 Identifikationen auf einer Domain hosten:

```json
{
  "names": {
    "alice": "b0635d6a9851d3aed0cd6c495b282167acf761729078d975fc341b22650b07b9",
    "bob": "3bf0c63fcb93463407af97a5e5ee64fa883d107ef9e558472c4eb9aaaefa459d",
    "carol": "82341f882b6eabcd2ba7f1ef90aad961cf074af15b9ef44a09f9d2a8fbfbe6a2"
  }
}
```

### Dein Setup Verifizieren

**Methode 1: Dein Client**

1. Füge das NIP-05 zu deinem Profil hinzu
2. Speichere Änderungen
3. Suche nach einem Häkchen ✓ oder "verifiziert" Badge
4. Kann ein paar Minuten zur Propagierung dauern

**Methode 2: Nostr Explorer**

1. Besuche einen Nostr Explorer wie nostr.guru
2. Suche nach deinem NIP-05
3. Prüfe, ob es zu deinem npub auflöst

**Methode 3: Direkter Test (Kommandozeile)**

```bash
curl https://deinedomain.com/.well-known/nostr.json
```

**Wie Erfolg Aussieht:**

- ✅ Client zeigt Verifizierungs-Badge
- ✅ Andere können dich über dein NIP-05 finden
- ✅ Dein Profil zeigt deinen menschenlesbaren Namen

### Datenschutz-Überlegungen

- NIP-05 verknüpft deinen npub mit einer Domain
- Dies könnte dich deanonymisieren, wenn die Domain deine echten Infos hat
- Nutze kostenlose Anbieter für pseudonyme Konten
- Nutze deine eigene Domain, wenn du identifiziert werden möchtest
