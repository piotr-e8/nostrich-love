Nostr لديه نظام بيئي غني من الأدوات والخدمات التي تجعل استخدام البروتوكول أسهل. إليك قائمة مختارة من الأدوات الأساسية مرتبة حسب الفئة.

<Callout variant="info">
  **نصيحة سريعة:** أضف هذه الصفحة إلى المفضلة! من المحتمل أن تعود إليها أثناء استكشاف ميزات Nostr المختلفة.
</Callout>

## أدوات إدارة المفاتيح

### محولات ومولدات المفاتيح

**Nostr Tools (محول المفاتيح)**
- **الرابط:** [nostr-tools.com](https://nostr-tools.com)
- **ما يفعله:** التحويل بين صيغ npub/hex/nsec
- **لماذا تستخدمه:** مفيد للمطورين أو عندما تحتاج إلى صيغ مفاتيح مختلفة

**NAK (Nostr Army Knife)**
- **الرابط:** [nak.nostr.com](https://nak.nostr.com)
- **ما يفعله:** أداة سطر أوامر وواجهة ويب لعمليات Nostr
- **الميزات:** توليد المفاتيح، توقيع الأحداث، التفاعل مع الـ relay، تصحيح الأخطاء
- **الأفضل لـ:** المطورين والمستخدمين المتقدمين الذين يحتاجون إلى أدوات CLI

**مولد مفاتيح Nostr**
- **ما يفعله:** توليد أزواج مفاتيح جديدة بدون اتصال
- **لماذا تستخدمه:** إنشاء مفاتيح في بيئة آمنة معزولة

### النسخ الاحتياطي والاستعادة

**أفضل ممارسات تخزين المفاتيح**
- مديرو كلمات المرور (Bitwarden، 1Password)
- مفاتيح الأمان المادية (YubiKey)
- نسخ احتياطية ورقية (مكتوبة ومخزنة بأمان)
- محركات أقراص USB مشفرة

<Callout variant="warning">
  **ملاحظة أمان:** لا تخزن nsec (مفتاحك الخاص) في ملفات نصية عادية، أو البريد الإلكتروني، أو التخزين السحابي بدون تشفير.
</Callout>

## استضافة الوسائط

### استضافة الصور ومقاطع الفيديو

**nostr.build**
- **الرابط:** [nostr.build](https://nostr.build)
- **ما يفعله:** استضافة مجانية للصور ومقاطع الفيديو لـ Nostr
- **الميزات:** رفع السحب والإفلات، روابط فورية، توصيل CDN
- **الأفضل لـ:** مشاركة الصور في المنشورات

**NostrImg**
- **الرابط:** [nostrimg.com](https://nostrimg.com)
- **ما يفعله:** خدمة استضافة صور بسيطة
- **الميزات:** تحميلات سريعة، تخزين دائم

### مشاركة الملفات

**Nostr Files**
- **الرابط:** [nostrfiles.com](https://nostrfiles.com)
- **ما يفعله:** استضافة ملفات عامة لمستخدمي Nostr
- **الأفضل لـ:** ملفات PDF والمستندات والملفات الأخرى

## الهوية والتحقق

### مزودو NIP-05

**NostrPlebs**
- **الرابط:** [nostrplebs.com](https://nostrplebs.com)
- **ما يفعله:** معرفات NIP-05 (you@nostrplebs.com)
- **التكلفة:** مدفوع فقط - 12,500-65,000 satoshi/سنة (التسعير بناءً على طول اسم المستخدم)
- **ملاحظة:** لا يوجد مستوى مجاني
- **الأفضل لـ:** الحصول على معرف قابل للقراءة بشري بسرعة

**NostrCheck**
- **الرابط:** [nostrcheck.me](https://nostrcheck.me)
- **ما يفعله:** NIP-05 + أدوات تحقق إضافية
- **الميزات:** مستوى مجاني، أدوات مساعدة إضافية

**GetAlby**
- **الرابط:** [getalby.com](https://getalby.com)
- **ما يفعله:** محفظة Lightning + NIP-05
- **الأفضل لـ:** الجمع بين المدفوعات والهوية

## التحليلات والاكتشاف

### تحليلات Zap

**Zaplife**
- **الرابط:** [zaplife.lol](https://zaplife.lol)
- **ما يفعله:** تتبع نشاط Zap والأرباح
- **الميزات:** أفضل محتوى تم zap، بيانات تاريخية، لوحات المتصدرين
- **الأفضل لـ:** المبدعين لتتبع أرباحهم

### اكتشاف الشبكة والإحصائيات

**Stats.OtherStuff**
- **الرابط:** [stats.otherstuff.org](https://stats.otherstuff.org)
- **ما يفعله:** إحصائيات وتحليلات شبكة Nostr
- **الميزات:** المقاييس العالمية، إحصائيات الـ relay، بيانات نمو الشبكة
- **الأفضل لـ:** فهم النظام البيئي الكلي لـ Nostr

**Primal Explore**
- **الرابط:** [primal.net/explore](https://primal.net/explore)
- **ما يفعله:** اكتشاف المحتوى والمستخدمين المتداول
- **الميزات:** موجزات المواضيع، المنشورات المتداولة، توصيات المستخدمين

## أدوات Relay

### قوائم ومراقبة Relay

**Nostr.watch**
- **الرابط:** [nostr.watch](https://nostr.watch)
- **ما يفعله:** مراقبة وقت تشغيل الـ relay والأداء
- **الميزات:** الحالة في الوقت الفعلي، مراقبة زمن الاستجابة، خريطة عالمية
- **الأفضل لـ:** إيجاد relays موثوقة

**أدوات Relay**
- قوائم relay متنوعة يتم صيانتها من قبل المجتمع
- تحقق من nostr.watch للتوصيات الحالية

### برنامج Relay

**strfry**
- **ما يفعله:** برنامج relay عالي الأداء
- **الأفضل لـ:** تشغيل relay خاص بك

**nostr-rs-relay**
- **ما يفعله:** تنفيذ relay مبني على Rust
- **الأفضل لـ:** المستخدمين التقنيين الذين يرغبون في الاستضافة الذاتية

## Lightning والـ Zaps

### المحافظ

**Alby** (امتداد المتصفح)
- **الرابط:** [getalby.com](https://getalby.com)
- **الأفضل لـ:** مستخدمي سطح المكتب/الويب
- **الميزات:** تكامل المتصفح، Nostr Wallet Connect

**Phoenix** (الجوال)
- **الرابط:** [phoenix.acinq.co](https://phoenix.acinq.co)
- **الأفضل لـ:** مستخدمي الجوال الذين يريدون الاحتفاظ الذاتي
- **الميزات:** غير حافظ، إدارة تلقائية للقنوات

**Wallet of Satoshi** (الجوال)
- **الأفضل لـ:** المبتدئين تمامًا
- **الميزات:** أسهل إعداد، عنوان Lightning مرفق

**Zeus** (الجوال)
- **الرابط:** [zeusln.app](https://zeusln.app)
- **الأفضل لـ:** المستخدمين المتقدمين، مشغلي العقد
- **الميزات:** الاتصال بعقدتك الخاصة، ميزات متقدمة

**Mutiny** (ويب/جوال)
- **الرابط:** [app.mutinywallet.com](https://app.mutinywallet.com)
- **الأفضل لـ:** الاحتفاظ الذاتي عبر المتصفح
- **الميزات:** لا يحتاج إلى متجر تطبيقات، حفظ اتحادي

### أدوات Zap

**ZapSplits**
- **ما يفعله:** تقسيم إيرادات Zap تلقائيًا
- **الأفضل لـ:** المحتوى التعاوني (بودكاست، مشاريع الفريق)

**Zap Stream**
- **ما يفعله:** إشعارات Zap في الوقت الفعلي
- **الأفضل لـ:** الأحداث المباشرة، البثوث

## أدوات المطورين

### المكتبات وSDKs

**nostr-tools (JavaScript)**
- **GitHub:** [github.com/nbd-wtf/nostr-tools](https://github.com/nbd-wtf/nostr-tools)
- **ما يفعله:** مكتبة JavaScript الأساسية لـ Nostr
- **الأفضل لـ:** بناء تطبيقات الويب

**NDK (Nostr Development Kit)**
- **GitHub:** [github.com/nostr-dev-kit/ndk](https://github.com/nostr-dev-kit/ndk)
- **ما يفعله:** SDK شامل لـ Nostr باستخدام TypeScript
- **الميزات:** React hooks، إدارة الذاكرة المؤقتة، تحسين تجمع الـ relay
- **الأفضل لـ:** تطبيقات TypeScript/React الحديثة

**Khatru**
- **GitHub:** [github.com/fiatjaf/khatru](https://github.com/fiatjaf/khatru)
- **ما يفعله:** إطار Go لبناء relays Nostr
- **الميزات:** تصميم معياري، سهل التوسيع، جاهز للإنتاج
- **الأفضل لـ:** المطورين الذين يبنون تطبيقات relay مخصصة

**Nostr Python**
- مكتبات Python متنوعة لتطوير Nostr

**Nostr Rust**
- تطبيقات Rust لتطبيقات عالية الأداء

## الخصوصية والأمان

### تطبيقات Signer

**Primal Signer (iOS)**
- **مدمج في تطبيق Primal**
- **ما يفعله:** تخزين مفتاح آمن مع مصادقة بيومترية
- **الميزات:** حماية FaceID/TouchID، لا يحتاج إلى تطبيق منفصل
- **الأفضل لـ:** مستخدمي iOS الذين يريدون أمانًا مدمجًا

**Amber (Android)**
- **تطبيق signer مخصص لنظام Android**
- **ما يفعله:** توقيع مفتاح آمن مع مطالبات موافقة
- **الميزات:** دعم مفاتيح متعددة، طلبات توقيع مفصلة
- **الأفضل لـ:** مستخدمي Android الذين يريدون أقصى قدر من الأمان

**تطبيقات Signer الأخرى**
- تطبيقات مخصصة متنوعة لتوقيع المفاتيح بأمان
- أبقِ nsec خارج جهازك الرئيسي
- ابحث في متجر التطبيقات عن "Nostr signer"

### VPN وTor

**دعم Tor**
- العديد من العملاء يدعمون Tor لتحسين الخصوصية
- تحقق من وثائق العميل للإعداد
