## Zaps क्या हैं? ⚡

Zaps Lightning Network पर भेजे गए Bitcoin टिप्स हैं। वे Nostr की मूल मूल्य परत हैं—उपयोगकर्ताओं को असली पैसे से उस कंटेंट को पुरस्कृत करने की अनुमति देती हैं जो उन्हें पसंद है।

इन्हें "मूल्य वाली लाइक्स" मानें—ऐसे लोगों का समर्थन करने का तरीका जिनका कंटेंट आप पसंद करते हैं।

### Zaps कैसे काम करते हैं

1. **आप अच्छा कंटेंट बनाते हैं** → पोस्ट, थ्रेड, या रिप्लाई
2. **कोई इसका आनंद लेता है** → वे ⚡ zap बटन क्लिक करते हैं
3. **वे सैटोशी भेजते हैं** → Bitcoin की छोटी मात्रा (1000 सैट्स = ~$0.30)
4. **आप तुरंत प्राप्त करते हैं** → पैसा आपके वॉलेट में दिखता है
5. **सबको दिखता है** → Zaps सार्वजनिक हैं और सामाजिक प्रमाण बनाते हैं

### Zaps क्रांतिकारी क्यों हैं

**पारंपरिक सोशल मीडिया:**

- लाइक्स मुफ्त और बेकार हैं
- प्लेटफ़ॉर्म सभी विज्ञापन राजस्व रखता है
- क्रिएटर्स को कुछ नहीं मिलता
- एंगेजमेंट खोखला है

**Zaps के साथ Nostr:**

- हर लाइक में असली मूल्य हो सकता है
- कोई प्लेटफ़ॉर्म कट नहीं लेता
- सीधे क्रिएटर समर्थन
- सार्थक एंगेजमेंट

### वास्तविक उदाहरण

- डेवलपर को बग फिक्स के लिए 100,000 सैट्स ($30) मिलते हैं
- कलाकार को अपना काम साझा करने पर zap मिलता है
- लेखक को अंतर्दृष्टिपूर्ण थ्रेड्स के लिए Bitcoin मिलता है
- मीम क्रिएटर को वायरल कंटेंट के लिए टिप्स मिलते हैं

### Zaps कैसे दिखते हैं

समर्थित क्लाइंट्स में, zaps ऐसे दिखते हैं:

- ⚡ लाइटनिंग बोल्ट आइकन
- Zap की गई राशि (जैसे, "21 सैट्स")
- पोस्ट पर कुल राशि
- जब आपको zap प्राप्त होता है तो विशेष सूचनाएं

### अपना वॉलेट कनेक्ट करना

#### चरण-दर-चरण: Alby + वेब क्लाइंट

1. **Alby एक्सटेंशन इंस्टॉल करें**
   - Chrome/Firefox: [getalby.com](https://getalby.com)
   - अकाउंट बनाएं या मौजूदा उपयोग करें

2. **अपना कनेक्शन स्ट्रिंग प्राप्त करें**
   - Alby डैशबोर्ड → API Keys
   - या: प्रोफ़ाइल → Nostr Wallet Connect

3. **क्लाइंट से कनेक्ट करें**
   - अपने Nostr क्लाइंट में (Primal, Iris, आदि)
   - Settings → Wallet → Connect
   - कनेक्शन स्ट्रिंग पेस्ट करें

4. **छोटे Zap से जांचें**
   - एक पोस्ट खोजें जो आपको पसंद हो
   - ⚡ बटन क्लिक करें
   - 10 सैट्स भेजें

#### चरण-दर-चरण: Phoenix + मोबाइल क्लाइंट

1. **Phoenix डाउनलोड करें**
   - App Store / Play Store
   - वॉलेट बनाएं (सीड फ्रेज़ बैकअप करें!)

2. **अपने वॉलेट में फंड जोड़ें**
   - Bitcoin खरीदें या कहीं से प्राप्त करें
   - शुरू करने के लिए कम से कम 10,000 सैट्स चाहिए

3. **LNURL या Lightning पता प्राप्त करें**
   - Phoenix → प्राप्त करें → Lightning पता
   - `yourname@phoenix.wallet` या LNURL कॉपी करें

4. **Nostr प्रोफ़ाइल में जोड़ें**
   - क्लाइंट → प्रोफ़ाइल → संपादित करें
   - Lightning पता पेस्ट करें

#### चरण-दर-चरण: Wallet of Satoshi + मोबाइल क्लाइंट

1. **Wallet of Satoshi डाउनलोड करें**
   - ऐप स्टोर में जाएं (iOS/Android)
   - "Wallet of Satoshi" खोजें
   - डाउनलोड और इंस्टॉल करें
   - ऐप खोलें (कोई अकाउंट ज़रूरी नहीं!)

2. **अपना Lightning पता प्राप्त करें**
   - "प्राप्त करें" टैप करें
   - अपना Lightning पता देखें
   - यह ऐसा दिखता है: `username@walletofsatoshi.com`
   - इो लिख लें—आपको इसकी ज़रूरत होगी

3. **अपने Nostr प्रोफ़ाइल में जोड़ें**
   - अपना Nostr क्लाइंट खोलें (Damus, Amethyst, Iris, आदि)
   - प्रोफ़ाइल संपादित करें पर जाएं
   - "Lightning पता" या "LN पता" फ़ील्ड खोजें
   - अपना पता पेस्ट करें
   - परिवर्तन सहेजें

4. **सत्यापित करें कि यह काम करता है**
   - अपनी प्रोफ़ाइल पर ⚡ आइकन देखें
   - एक दोस्त से टेस्ट zap भेजने को कहें (100 सैट्स)
   - अपना वॉलेट जांचें—तुरंत प्राप्त होना चाहिए
   - आपके क्लाइंट में zap सूचना दिखनी चाहिए

## Zaps भेजना 💸

### पोस्ट Zap कैसे करें

1. **पसंद आई पोस्ट खोजें**
2. **⚡ बटन टैप करें**
3. **राशि चुनें** या कस्टम दर्ज करें
4. **संदेश जोड़ें** (वैकल्पिक)
5. **पुष्टि करें** और भेजें!

### Zap राशि शिष्टाचार

**त्वरित संदर्भ:**

| राशि           | कब उपयोग करें                    |
| ---------------- | ------------------------------ |
| 10-50 सैट्स       | छोटी सराहना             |
| 100-500 सैट्स     | अच्छी पोस्ट/थ्रेड               |
| 1,000-5,000 सैट्स | बढ़िया कंटेंट, पॉडकास्ट एपिसोड |
| 10,000+ सैट्स     | असाधारण मूल्य, कला, टूल   |

> 💡 **अनुभवजन्य नियम**: वह Zap करें जो कंटेंट आपके लिए मूल्यवान है। कोई भी राशि बहुत छोटी नहीं है!

### कस्टम संदेश

ज़्यादातर क्लाइंट्स आपको अपने Zap के साथ संदेश जोड़ने देते हैं:


## Zaps प्राप्त करना 💰

### LNURL सेटअप करना

Zaps प्राप्त करने के लिए, आपको कॉन्फ़िगर करना होगा कि वे कहां जाएं:

1. **अपना Lightning पता या LNURL प्राप्त करें**
   - अपने वॉलेट से (Alby, Phoenix, आदि)
   - प्रारूप: `yourname@provider.com`

2. **अपनी प्रोफ़ाइल में जोड़ें**

   ```
   क्लाइंट → प्रोफ़ाइल → संपादित करें → Lightning पता
   पेस्ट करें: yourname@getalby.com
   ```

3. **सत्यापित करें कि काम करता है**
   - एक दोस्त से 10 सैट्स भेजने को कहें
   - या टेस्टनेट फ़ॉसेट उपयोग करें

### Zap सूचनाएं

**ज़्यादातर क्लाइंट्स में:**

- Zap प्राप्त होने पर पुश सूचना
- सूचना टैब में Zap इतिहास
- देख सकते हैं कि किसने आपको Zap किया

**गोपनीयता नोट:**
Zaps अर्ध-सार्वजनिक हैं। जबकि कुछ सेटअप में राशियां निजी हो सकती हैं, यह तथ्य कि आपने Zap किया (या आपको Zap प्राप्त हुआ) दिखाई देता है।

## Zap स्प्लिट्स [उन्नत]

<Note type="advanced">
  Zap राजस्व स्वचालित रूप से साझा करने का वैकल्पिक फ़ीचर।
</Note>

### Zap स्प्लिट्स क्या हैं?

जब कोई आपकी पोस्ट पर Zap करता है, तो भुगतान सहयोगियों के साथ स्वचालित रूप से विभाजित होता है:

```
उदाहरण: पॉडकास्ट एपिसोड
├── 70% → होस्ट (आप)
├── 20% → प्रोड्यूसर
└── 10% → एडिटर
```

### स्प्लिट्स सेटअप करना

1. **अपने क्लाइंट में**: "Zap Splits" या "Recipients" खोजें
2. **सहयोगी जोड़ें**: उनके Lightning पते दर्ज करें
3. **प्रतिशत सेट करें**: कुल 100% होना चाहिए
4. **सहेजें**: भविष्य के Zaps स्वतः विभाजित होंगे

### सामान्य उपयोग मामले

- **पॉडकास्ट**: होस्ट और मेहमानों के बीच विभाजित
- **सहयोगी पोस्ट**: सह-लेखकों के साथ साझा
- **कला**: प्रेरणा स्रोतों के साथ विभाजित
- **ओपन सोर्स**: निर्भरताओं को फंड

## Zaps ट्रबलशूटिंग 🔧

### "Zap बटन काम नहीं कर रहा"

- वॉलेट कनेक्ट है जांचें (Settings → Wallet)
- पर्याप्त बैलेंस सुनिश्चित करें
- क्लाइंट रीलोड करने की कोशिश करें

### "वॉलेट कनेक्ट नहीं हो रहा"

- अपना कनेक्शन स्ट्रिंग सही है सत्यापित करें
- अपना वॉलेट अनलॉक है जांचें
- कुछ वॉलेट्स को "ऑनलाइन" होना ज़रूरी है (Phoenix)

### "Zaps दिख नहीं रहे"

- Zaps प्रोसेस होने में कुछ सेकंड लगते हैं
- कुछ क्लाइंट सूचनाएं बैच में दिखाते हैं
- पुष्टि के लिए सीधे अपना वॉलेट जांचें

### "Zaps प्राप्त नहीं हो रहे"

- अपना Lightning पता प्रोफ़ाइल में सही है सत्यापित करें
- छोटी राशि से जांचें
- सुनिश्चित करें कि आपका वॉलेट चल रहा है (नन-कस्टोडियल)

## सर्वोत्तम अभ्यास

### करें:

- ✅ मूल्य देने वाले कंटेंट को Zap करें
- ✅ एक दोस्ताना संदेश जोड़ें
- ✅ सीखते समय छोटी राशि से शुरू करें
- ✅ स्वागत Zaps के साथ नए लोगों का समर्थन करें
- ✅ अपने वॉलेट में कुछ सैट्स रखें

### न करें:

- ❌ Zap करने का दबाव महसूस करें
- ❌ अपसाधना से ज़्यादा Zap करें
- ❌ बदले में Zaps की उम्मीद करें
- ❌ कम गुणवत्ता वाला कंटेंट Zaps की उम्मीद से स्पैम करें
- ❌ अपना वॉलेट सीड बैकअप भूलें
