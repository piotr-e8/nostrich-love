रिले Nostr के डाकघर हैं। वे वे जगह हैं जहाँ आपके संदेश रहते हैं और वे अन्य उपयोगकर्ताओं तक पहुँचने का तरीका हैं।

## डाकघर एनालॉजी 🏤

Nostr को दुनिया भर में डाकघरों के नेटवर्क की तरह कल्पना करें।

- **आपके** पास एक मेलबॉक्स है (आपकी कुंजियाँ)
- **रिले** डाकघर हैं
- **पोस्टें** वे पत्र हैं जो आप भेजते हैं

पारंपरिक सोशल मीडिया से मुख्य अंतर: **आप चुनते हैं कि अपनी डाक कहाँ भेजनी है।**

```
पारंपरिक सोशल मीडिया:    Nostr:
┌──────────────────┐        ┌──────────────────┐
│ एक बड़ा सर्वर   │        │ कई डाकघर      │
│ (Twitter/X)      │        │ (रिले)         │
│                  │        │                  │
│ सब एक          │        │ आप चुनते हैं   │
│ एक जगह         │        │ कौन से उपयोग करने हैं │
└──────────────────┘        └──────────────────┘
```

### विकल्प की शक्ति

Nostr में, आप एक सेवा प्रदाता पर बंदे नहीं हैं। आप कर सकते हैं:

- किसी भी रिले को पोस्ट भेजें
- कई रिले से कनेक्ट करें
- कभी भी रिले बदलें
- अपना खुद का रिले चलाएं

## पोस्टें क्यों सिंक नहीं होतीं 🔄

यहाँ सबसे आम उलझन है जो नए उपयोगकर्ता �面对 करते हैं:

> "मैंने कुछ पोस्ट किया लेकिन मेरा दोस्त उसे नहीं देख सकता!"

### दृश्य व्याख्या

```
आपका कनेक्शन                    दोस्त का कनेक्शन
     │                                  │
     ▼                                  ▼
┌──────────┐                     ┌──────────┐
│ रिले A   │         ❌          │ रिले B   │
│ (wss://...)│      कोई लिंक नहीं      │(wss://...)│
└──────────┘                     └──────────┘
     │                                  │
   आपकी पोस्टें                       दोस्त की पोस्टें
```

**यदि आप रिले A पर पोस्ट करते हैं और आपका दोस्त केवल रिले B उपयोग करता है, तो वे आपकी पोस्ट नहीं देखेंगे।**

### समाधान: कई रिले से कनेक्ट करें

```
आपका कनेक्शन
     │
┌────┴────┐
│ रिले A │
│ रिले B │  ← दोनों से कनेक्ट करें!
│ रिले C │
└────┬────┘
     │
   आपकी पोस्टें → अधिक लोगों तक पहुँचती हैं
```

अधिकांश Nostr क्लाइंट आपको कई डिफ़ॉल्ट रिले से कनेक्ट करते हैं। लेकिन इसे समझना मदद करता है जब आप:

- किसी की सामग्री नहीं देख पा रहे हैं
- एक विशेष समुदाय में शामिल होना चाहते हैं
- गायब पोस्टों का समाधान करना चाहते हैं

## रिले चुनना 🔌

### डिफ़ॉल्ट सिफारिशें

यदि आप अभी शुरू कर रहे हैं, तो इन लोकप्रिय, विश्वसनीय रिले पर टिके रहें:

| रिले                      | विवरण      | विश्वसनीयता |
| -------------------------- | ---------------- | ----------- |
| `wss://relay.damus.io`     | Damus मुख्य रिले | ⭐⭐⭐⭐⭐  |
| `wss://nostr.wine`         | सामान्य रिले    | ⭐⭐⭐⭐    |
| `wss://relay.snort.social` | Snort सोशल     | ⭐⭐⭐⭐    |

### रुचि-आधारित खोज

समुदाय अक्सर केंद्रित चर्चाओं के लिए अपने रिले चलाते हैं:

- **Bitcoin**: `wss://nostr.bitcoiner.social`
- **विकास**: `wss://relay.nostrdevs.com`
- **कला**: `wss://relay.nostrich.art`

### मुफ्त बनाम भुगतान वाले रिले

**मुफ्त रिले**

- सभी के लिए खुले
- रेट लिमिट हो सकती है
- स्पैम से भर सकते हैं
- शुरुआती लोगों के लिए बढ़िया

**भुगतान वाले रिले**

- आमतौर पर छोटी फीस आवश्यक (अक्सर 1000-5000 sats/महीना)
- बेहतर प्रदर्शन
- कम स्पैम
- रिले ऑपरेटर्स का समर्थन

> 💡 **टिप**: मुफ्त रिले से शुरू करें। आप हमेशा बाद में भुगतान वाले जोड़ सकते हैं।

## उन्नत: आउटबॉक्स मॉडल (NIP-65) [उन्नत]

<Note type="advanced">
  यह खंड वैकल्पिक है। आप NIP-65 को समझे बिना Nostr का बहुत अच्छा उपयोग कर सकते हैं।
</Note>

### NIP-65 क्या है?

NIP-65 रिले को संभालने का एक बुद्धिमान तरीका पेश करता है जिसे "आउटबॉक्स मॉडल" कहा जाता है।

**के बजाय**: आप मैन्युअली 10+ रिले से कनेक्ट कर रहे हैं
**आप करते हैं**: अपनी पसंदीदा रिले सूची एक बार प्रकाशित करें, क्लाइंट्स को समझने दें

### यह कैसे काम करता है

```
1. आप एक रिले सूची प्रकाशित करते हैं:
   {
     "read": ["wss://relay-a.com"],
     "write": ["wss://relay-b.com"]
   }

2. अन्य क्लाइंट्स इसे पढ़ते हैं और जानते हैं:
   - आपकी पोस्टें कहाँ खोजनी हैं (रीड रिले)
   - आपको संदेश कहाँ भेजने हैं (राइट रिले)
```

### व्यक्तिगत रिले सेट करना

उन्नत उपयोगकर्ताओं के लिए, अपना रिले चलाना आपको देता है:

- **पूर्ण नियंत्रण** अपने डेटा पर
- **परिपूर्ण विश्वसनीयता** (अन्य पर कोई निर्भरता नहीं)
- **गोपनीयता** (रिले पर केवल आपका डेटा)

लोकप्रिय व्यक्तिगत रिले सॉफ़्टवेयर:

- [strfry](https://github.com/hoytech/strfry) - तेज़ C++ इम्प्लीमेंटेशन
- [nostr-rs-relay](https://gitlab.com/soapbox-pub/nostr-rs-relay) - Rust इम्प्लीमेंटेशन

> 📚 विस्तृत सेटअप निर्देशों के लिए हमारी [रिले गाइड](/hi/guides/relay-guide) देखें।

## त्वरित संदर्भ

### सामान्य रिले कमांड

अधिकांश क्लाइंट्स में, आप कर सकते हैं:

- **रिले जोड़ें**: सेटिंग्स → रिले → जोड़ें
- **रिले हटाएं**: रिले पर लंबा प्रेस/क्लिक → हटाएं
- **स्थिति जाँचें**: रिले सूची कनेक्शन स्थिति दिखाती है

### सर्वोत्तम अभ्यास

1. **4-8 रिले से कनेक्ट करें** अच्छे कवरेज के लिए
2. **एक "राइट" रिले शामिल करें** जहाँ आप हमेशा पोस्ट करते हैं
3. **रिले अपटाइम जाँचें** उस पर भरोसा करने से पहले
4. **अपनी रिले सूची अपडेटेड रखें** जैसे-जैसे नेटवर्क बढ़ता है

## समस्या समाधान

### "मैं कोई पोस्ट नहीं देख सकता"

- जाँचें कि क्या आप किसी रिले से कनेक्ट हैं (सेटिंग्स → रिले)
- ऊपर सूची से लोकप्रिय रिले जोड़ने का प्रयास करें
- सामग्री लोड होने के लिए कुछ क्षण प्रतीक्षा करें

### "मेरी पोस्टें गायब हो जाती हैं"

- कुछ रिले जगह बचाने के लिए पुरानी सामग्री डिलीट करते हैं
- अधिक रिले से कनेक्ट करें रिडंडेंसी के लिए
- स्थायी भंडारण के लिए भुगतान वाले रिले पर विचार करें

### "रिले कनेक्ट नहीं हो रहा"

- अपना इंटरनेट कनेक्शन जाँचें
- रिले URL को ब्राउज़र में आज़माएँ (ऐरर या ws पेज दिखना चाहिए)
- रिले डाउन हो सकता है - दूसरा आज़माएं
