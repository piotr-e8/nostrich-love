## यह क्यों Important है

Twitter या Instagram के विपरीत, Nostr **आपको** आपकी identity के in-charge puts करता है। कोई companies नहीं हैं जो आपको ban करें, कोई algorithms नहीं हैं जो आपका content suppress करें, और कोई customer service नहीं है जो आपका data lose करे। यह freedom responsibility के साथ आता है—आप अपनी keys own करते हैं, आप अपना account control करते हैं।

### इतनी लंबी क्यों?

वे strings gibberish दिखती हैं क्योंकि वे cryptographic keys हैं। यहाँ क्यों:

- **256-bit security:** इसे guess या crack करना impossible बनाता है
- **Random generation:** Computers भी इसे predict नहीं कर सकते
- **One-way math:** आप public key से private key figure नहीं कर सकते

इस तरह सोचें: Earth पर sand के grains से ज्यादा possible private keys हैं। कोई आपके guess नहीं कर रहा।

## The 3-2-1 Backup Rule (2 मिनट)

यह rule professional data management से आता है। इसे religiously follow करें।

<BackupChecklist client:load />

### Rule Explained

**आपके nsec की 3 copies**

- एक enough नहीं। दो better। तीन safe।
- अगर एक fail हो, आपके पास दो backups

**2 different media types**

- Digital: Password manager, encrypted file
- Physical: Paper hand से लिखा, metal plate
- अलग types क्यों? Digital और physical अलग तरह fail होते हैं

**1 offsite location**

- कम से कम एक copy कहीं और होनी चाहिए
- Cloud storage offsite count होता है (अगर encrypted)
- Safe deposit box, trusted friend/family member

### Backup Methods Ranked

**BEST (यह करें):**

1. ✅ Password manager (1Password, Bitwarden)
2. ✅ Paper पर लिखा हुआ, safe में stored
3. ✅ Encrypted USB drive different location में

**GOOD:**

4. ✅ Encrypted cloud storage (iCloud/Google Drive with encryption)
5. ✅ Metal seed plate (fireproof/waterproof)

**NEVER DO:**

- ❌ Phone पर screenshot (cloud को sync)
- ❌ Unencrypted notes app
- ❌ खुद को email
- ❌ Text message
- ❌ Browser autocomplete में save

### अगर आप अपनी Keys खो दें तो क्या होगा?

**यही कारण है कि 3-2-1 backup rule matter करता है।**

Centralized platforms के विपरीत, Nostr में कोई "forgot password" button या customer support नहीं है जो आपका account recover करे। लेकिन चिंता मत करें—नीचे दिए गए simple backup steps follow करना आपको safe रखेगा।

**इस तरह सोचें:** आप अपनी life savings cash के रूप में pocket में नहीं रखेंगे। आप ज्यादातर bank में रखेंगे (multiple backups) और सिर्फ जितना जरूरत हो उतना carry करेंगे। आपका nsec similar है—इसे securely store करें, सिर्फ अपने phone पर नहीं।

## Security Best Practices (2 मिनट)

### The DON'Ts (दूसरों की गलतियों से सीखें)

**DON'T अपनी Keys Screenshot करें**

- Screenshots cloud को sync करते हैं (iCloud, Google Photos)
- Cloud accounts hack हो जाते हैं
- Photo delete करना इसे backups से remove नहीं करता

**DON'T Unencrypted Notes में Save करें**

- Apple Notes, Google Keep, etc. encrypted नहीं हैं
- जिसके पास आपका phone/computer है वे उन्हें पढ़ सकते हैं
- Default से cloud sync होता है

**DON'T किसी को Share करें**

- न आपके spouse
- न आपके best friend
- न "Nostr support" (कोई support नहीं है)
- न किसी को, कभी नहीं

### The DOs (Best Practices)

**DO Password Manager Use करें**

- 1Password, Bitwarden, KeePass
- Encrypted, backed up, accessible
- Clients के लिए strong passwords भी generate करें

**DO Paper पर लिखें**

- Low-tech, highly reliable
- कोई batteries नहीं चाहिए
- Safe, lockbox, या hidden location में store करें

**DO Nostr Signer Apps Use करें** [ADVANCED]

- Apps जैसे Amber (Android) आपकी keys securely store करते हैं
- Clients signatures request करते हैं keys store करने की बजाय
- Extra security layer add करता है
- Serious users के लिए recommended
