## 什么是闪电打赏？

闪电打赏（英文叫 zap，客户端里的按钮和 #zap 标签用的都是这个词）是通过闪电网络发送的比特币小费。它是 Nostr 的原生价值层，让人可以用真金白银奖励自己喜爱的内容。

把它想象成"有价值的小红心"，一种支持你喜爱的创作者的方式。

### 闪电打赏的工作原理

1. **你创建好内容** → 一条帖子、帖子串或回复
2. **有人喜欢它** → 他们点击 ⚡ 闪电打赏按钮
3. **他们发送聪** → 少量比特币（1000 聪远远不到一美元）
4. **你立即收到** → 钱出现在你的钱包里
5. **每个人都看到** → 闪电打赏是公开的，创造社交证明

### 为什么闪电打赏是革命性的

在通常那些平台上，点赞不花钱，所以也不值钱。你的作品替它们卖广告，钱进了平台的口袋。闪电打赏改变的是这个动作本身：有人按下那道闪电，真的比特币就从他的钱包出来，进到你的钱包，中间没有哪家公司抽走一个百分点。让发出者付出一点代价的欣赏，分量往往更重。

### 真实示例

一位插画师发了一张速写，第二天醒来收到素不相识的人打来的几千聪。一位作者写的长帖子串传了整整一周，这一周里打赏也一直没停。一位音乐人分享了一段粗糙的小样，赚回了一小时的录音棚钱。开发者也会被打赏，有时候一个下午替别人修好一个 bug，就是 100,000 聪（几十美元）。

## 钱包设置

在你能发送或接收闪电打赏之前，你需要一个闪电钱包。

### 推荐的钱包

#### 给初学者

**Primal Wallet**（内置于 Primal 应用）

- 内置于 Primal 客户端，零设置
- 自 Primal 3.0 起为基于 Spark 的自我托管钱包
- 网页、iOS 和 Android
- [primal.net](https://primal.net)

**Coinos**（网页钱包）

- 托管式网页钱包
- 提供 `you@coinos.io` 闪电地址
- 托管式，只放小额资金
- [coinos.io](https://coinos.io)

**Phoenix**（移动版）

- 用户友好
- 自我托管
- iOS 和 Android（2025 年 4 月起重新上架美国 App Store）
- 注意：自我托管意味着首次充值小额资金时会有少量链上/通道费用
- [phoenix.acinq.co](https://phoenix.acinq.co)

#### 给高级用户

**Alby Hub**（自我托管闪电节点）

- 云端或自托管运行
- 包含闪电地址
- 可搭配 Alby 浏览器扩展和 Alby Go
- 通过 NWC 连接到任何 Nostr 客户端
- [getalby.com](https://getalby.com)

**Zeus**（移动版）

- 连接到你自己的节点，或使用内置钱包
- 完全控制
- 高级用户功能
- [zeusln.com](https://zeusln.com)

### 托管 vs 非托管

**托管（Coinos 及其他托管式钱包）**

- ✅ 易于设置
- ✅ 更低费用
- ❌ 他们持有你的资金
- ❌ 可能需要 KYC

**非托管（Primal Wallet、Phoenix、Alby Hub、Zeus）**

- ✅ 你控制你的密钥
- ✅ 更好的隐私
- ❌ 稍微复杂
- ❌ 更高的链上费用

> **推荐**：小额资金先用托管式或客户端内置钱包起步。随着余额增长，升级到完全自我托管（Phoenix 或 Alby Hub）。

### Wallet of Satoshi 和 Mutiny 呢？

许多较旧的指南仍然推荐它们。这些信息已经过时了：

- **Mutiny 已关闭**：2024 年 8 月宣布停运，所有应用、服务和支持已于 2024 年 12 月 31 日终止。不要向它发送资金。
- **Wallet of Satoshi**：其经典的托管服务于 2023 年 11 月退出美国市场，并于 2026 年初在欧盟范围内停止。它已重新推出为基于 Spark、宣传为自我托管的钱包。那是另一个产品。

想要最简单的起步方式，请使用客户端内置钱包（如 Primal 的）或 Coinos。

### 连接你的钱包

#### 分步：Alby Hub + 网页客户端

1. **设置 Alby Hub**
   - 前往 [getalby.com](https://getalby.com)（云端或自托管）
   - Alby Hub 是一个自我托管的闪电节点，Alby 不再提供托管式余额
   - 浏览器扩展是可选的，可关联到你的 Hub

2. **创建 NWC 应用连接**
   - 在 Alby Hub 中创建一个新的应用连接
   - 复制 NWC 连接字符串

3. **连接到客户端**
   - 在你的 Nostr 客户端（Primal、Iris 等）
   - 设置 → 钱包 → 连接
   - 粘贴 NWC 连接字符串

4. **用小额闪电打赏测试**
   - 找到你喜欢的帖子
   - 点击 ⚡ 按钮
   - 发送 10 聪

#### 分步：Phoenix + 移动客户端

1. **下载 Phoenix**
   - App Store / Play Store
   - 创建钱包（备份助记词！）

2. **为你的钱包充值**
   - 购买比特币或从其他地方接收
   - 开始需要至少 10,000 聪

3. **了解 Phoenix 的接收限制**
   - Phoenix 提供的是闪电发票（invoice）
   - 它不提供大多数 Nostr 客户端期望的经典 `name@provider` 闪电地址
   - 其 `@phoenixwallet.me` 地址支持是一个实验性的 BIP-353 功能

4. **接收闪电打赏时，请搭配一个闪电地址**
   - 使用能提供闪电地址的钱包（客户端内置钱包、Coinos 或 Alby Hub）
   - 把 Phoenix 留作存放较大余额的自我托管钱包

#### 分步：客户端内置钱包（例如 Primal）

1. **在你的客户端中激活钱包**
   - 打开客户端的钱包区域并按提示激活
   - Primal 的内置钱包是自我托管的（网页/iOS/Android）

2. **获取你的闪电地址**
   - 钱包会显示你的闪电地址
   - 它看起来像这样：`username@provider.com`

3. **添加到你的 Nostr 个人资料**
   - 带内置钱包的客户端通常会自动填写个人资料中的闪电地址字段
   - 如果没有，转到编辑个人资料，粘贴你的地址并保存

4. **验证它是否有效**
   - 在你的个人资料上寻找 ⚡ 图标
   - 请朋友发送测试闪电打赏（100 聪）
   - 检查你的钱包，应该立即收到
   - 你应该在客户端中看到闪电打赏通知

<Callout variant="warning">
  **重要：** 如果使用自我托管钱包（Phoenix、Primal Wallet、Alby Hub、Zeus），写下你的钱包恢复助记词！如果你失去钱包访问权限，你就失去了你的比特币。没有例外。
</Callout>

## 发送闪电打赏

### 如何闪电打赏帖子

1. **找到你喜欢的帖子**
2. **点击 ⚡ 按钮**
3. **选择金额** 或输入自定义
4. **添加消息**（可选）
5. **确认** 并发送！

### 闪电打赏金额礼仪

**快速参考：**

| 金额           | 何时使用                    |
| ---------------- | ------------------------------ |
| 10-50 聪       | 小小的感谢             |
| 100-500 聪     | 优质帖子/帖子串             |
| 1,000-5,000 聪 | 很棒的内容，播客集 |
| 10,000+ 聪     | 非凡的价值，艺术，工具   |

> **经验法则**：按你觉得内容值多少来打赏，再小的金额也不嫌少！

### 自定义消息

大多数客户端都允许你在打赏时附上一条留言：

```
"谢谢你的帮助！"
"这个帖子串很棒，学到了很多"
"☕ 我请的咖啡"
```

这会让互动更有人情味，也能帮助创作者了解哪些内容引起了共鸣。

## 接收闪电打赏

### 设置你的闪电地址

要接收闪电打赏，你需要配置它们去哪里：

1. **获取你的闪电地址**
   - 从你的钱包（客户端内置钱包、Coinos、Alby Hub 等）
   - 格式：`yourname@provider.com`

2. **添加到你的个人资料**

   ```
   客户端 → 个人资料 → 编辑 → 闪电地址
   粘贴：yourname@getalby.com
   ```

3. **验证它是否有效**
   - 在钱包的发送界面里，往你自己的闪电地址打几聪试试
   - 或者请朋友给你打赏 10 聪来测试

### 闪电打赏通知

大多数客户端会在打赏到账的一瞬间推送通知，并在通知里保留一个打赏标签页，你可以往回翻，看谁在什么时候打了多少。

**隐私说明：**
闪电打赏是公开的。任何人打开一条帖子，都能看到它被打赏过、打了多少，因为金额就写在发布到中继上的打赏收据里。有些客户端提供匿名打赏，那会把发送者的名字从收据上去掉。无论哪种方式，金额都是看得见的。

## 闪电打赏拆分 [高级]

  用于自动分享闪电打赏收入的可选功能。

### 什么是闪电打赏拆分？

当有人闪电打赏你的帖子时，自动与协作者分摊付款：

<DiagramSplit
  title="示例：播客集"
  rows={[
    { percent: 70, label: "主持人（你）" },
    { percent: 20, label: "制作人" },
    { percent: 10, label: "编辑" },
  ]}
  caption="一笔闪电打赏，自动分给参与这一集制作的每个人。"
/>

### 设置拆分

拆分属于帖子，不属于你的账号。你要在写帖子的时候，在支持这个功能的客户端里设置它（用得最多的是 Amethyst），设好之后只对这一条笔记生效。并不存在某个开关，能把你此后发布的一切都悄悄拆分掉。

1. **在撰写帖子时**：在编辑界面里找"闪电打赏拆分""接收者"或类似的字样
2. **按 Nostr 身份添加协作者**：你用 npub 或搜索的方式选人，客户端会从对方的个人资料上读取闪电地址。个人资料里没有闪电地址的人，那份钱没地方收。
3. **给每个人分配份额**（可选）：这里填的是相对权重，不是百分比，所以 3 和 1 意味着一位协作者拿走四分之三。不填权重，打赏就平均分。
4. **发布**：这条笔记上的每一笔打赏，都按你设的方式分。

### 常见用例

- **播客**：在主持人和嘉宾之间拆分
- **协作帖子**：与合著者分享
- **艺术**：与灵感来源拆分
- **开源**：资助依赖项

## 记录你的闪电打赏

你想知道的大部分信息，客户端里已经有了。每条帖子都带着自己的打赏总额，通知里的打赏标签页会列出谁在什么时候发了多少。如果你用的是带内置钱包的客户端，比如 Primal，钱包界面会把进出的聪汇总在一处，历史一目了然。

目前还不存在真正意义上的打赏数据看板，所以别去找什么热门帖子排行或者支持者榜单了。[zaplife.lol](https://zaplife.lol) 倒是值得一看：它是一条实时流，显示此刻整个 Nostr 上正在发生的打赏，看着有意思，但谈不上是测量工具。

## 创作者最佳实践

### 最大化闪电打赏支持

**1. 创造价值**

- 教育内容
- 独特见解
- 娱乐
- 有用的工具/资源

**2. 保持一致**

- 定期发布
- 随时间建立信任
- 质量胜过数量

**3. 感谢支持者**

- 感谢打赏你的人
- 回复评论
- 建立关系

**4. 发出价值信号**

- 偶尔"欢迎闪电打赏"
- 表示感谢
- 不要乞求或要求

**5. 收入多元化**

- 不要仅依赖闪电打赏
- 提供付费内容/订阅
- 构建产品/服务
- 接受直接捐赠

### 税务考虑

<Callout variant="warning">
  **不是财务建议。** 咨询你所在司法管辖区的税务专业人士。

**一般原则：**

- 闪电打赏可能是应税收入
- 保留收据记录

- 持有的比特币 = 出售时的资本利得

**工具：**

- Koinly、CoinTracker 用于追踪
- 定期导出钱包历史

## 闪电打赏故障排除

### "闪电打赏按钮无法工作"

- 检查钱包是否已连接（设置 → 钱包）
- 确保你有足够的余额
- 尝试重新加载客户端

### "钱包无法连接"

- 验证你的连接字符串是否正确
- 检查你的钱包是否已解锁
- 一些钱包需要"在线"（Phoenix）

### "闪电打赏不显示"

- 闪电打赏需要几秒钟处理
- 一些客户端批量通知
- 直接检查你的钱包以确认

### "无法接收闪电打赏"

- 验证你的闪电地址是否在你的个人资料中
- 先用小额测试
- 确保你的钱包正在运行（非托管）
