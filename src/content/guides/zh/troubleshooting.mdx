## 问题："我的动态是空的" 📭

### 症状

- 没有帖子显示
- "未找到事件"消息
- 空白时间线

### 原因与解决方案

**1. 没有关注任何人**

- **原因**：没有关注的新账号
- **解决方案**：搜索用户或兴趣，关注 10-20 个账号
- **快速修复**：从 [找到社区](/zh/guides/finding-community) 指南关注热门账号

**2. 中继连接问题**

- **原因**：没有连接到任何中继
- **解决方案**：检查设置 → 中继，确保你连接到 3-5 个中继
- **快速修复**：添加热门中继：`wss://relay.damus.io`、`wss://nostr.wine`

**3. 客户端缓存为空**

- **原因**：新安装或清除数据
- **解决方案**：等待 30-60 秒让内容加载
- **快速修复**：下拉刷新（移动版）或按刷新按钮

### 预防

- 在设置期间连接到多个中继
- 立即关注活跃用户
- 保持客户端更新

## 问题："我看不到我的旧帖子" 🕐

### 症状

- 昨天/上周的帖子不见了
- 你的个人资料上"没有笔记"
- 不完整的帖子历史

### 原因与解决方案

**1. 中继存储限制**

- **原因**：免费中继删除旧内容以节省空间
- **解决方案**：连接到更多中继（增加冗余）
- **长期**：为重要内容使用付费中继或个人中继

**2. 不同的中继配置**

- **原因**：从客户端 A（中继 X,Y）发布，现在使用客户端 B（中继 Z）
- **解决方案**：确保两个客户端使用相同的中继
- **快速修复**：导入你的中继列表（NIP-65）

**3. 内容未广播**

- **原因**：客户端未能向所有中继发布
- **解决方案**：检查哪些中继收到了你的帖子
- **注意**：发布后，无法追溯地向新中继重新广播

### 什么同步与什么不同步

| 数据           | 跨客户端同步 | 注释                      |
| -------------- | -------------------- | -------------------------- |
| 你的帖子     | ✅ 是               | 如果发布到共享中继 |
| 你的关注   | ✅ 是               | 公开数据                |
| 你的粉丝 | ✅ 是               | 公开数据                |
| 你的个人资料   | ✅ 是               | 公开数据                |
| 草稿         | ❌ 否                | 每个客户端本地存储  |
| 应用设置   | ❌ 否                | 客户端特定            |
| 静音账号 | ⚠️ 有时         | 因客户端而异          |

## 问题："我的帖子没有显示" 📤

### 症状

- 发布了但没人看到
- 没有点赞/回复/闪电打赏
- 帖子在本地显示，但在其他客户端不显示

### 原因与解决方案

**1. 中继不接受帖子**

- **原因**：速率限制、被封禁，或中继宕机
- **解决方案**：检查中继状态，尝试不同的中继
- **测试**：你能在像 Primal 这样的网页客户端中看到你的帖子吗？

**2. 只连接到只读中继**

- **原因**：一些中继只允许读取，不允许写入
- **解决方案**：检查中继设置，确保你有"写入"中继
- **快速修复**：添加 `wss://relay.damus.io`（允许写入）

**3. 发帖太快**

- **原因**：达到速率限制
- **解决方案**：放慢速度，等待几分钟
- **注意**：大多数中继限制每秒 1-5 个帖子

## 问题："有人在冒充我" 🎭

### 症状

- 使用你的名字/照片的虚假账号
- 有人声称是你
- 困惑的粉丝询问哪个账号是真实的

### 原因与解决方案

**1. 获取 NIP-05 验证**

- **解决方案**：设置 NIP-05 身份（参见 [指南](/zh/guides/nip05-identity)）
- **为什么**：验证徽章区分真实与虚假

**2. 广泛分享你的 npub**

- **解决方案**：在其他平台上发布你真实的 npub
- **为什么**：人们可以加密验证你的身份

**3. 举报冒充者**

- **解决方案**：使用客户端举报功能或社区审核
- **注意**：无法删除他们的账号（去中心化），但可以屏蔽/静音

### 预防

- 尽快使用 NIP-05 验证自己
- 在 Twitter/网站上发布你的 npub
- 快速建立声誉，使你的真实账号显而易见

## 问题："动态中有垃圾邮件" 🗑️

### 症状

- 不需要的推广内容
- 机器人账号不断发帖
- 离题或不适当的内容

### 原因与解决方案

**1. 关注了垃圾邮件账号**

- **解决方案**：取消关注垃圾来源
- **更好**：不要批量关注；仔细策划

**2. 审核不良的中继**

- **解决方案**：断开与低质量中继的连接
- **更好**：使用付费或仅限邀请的中继

**3. 没有静音列表**

- **解决方案**：在客户端中创建静音列表
- **如何**：个人资料 → 静音账号 → 添加垃圾发送者

### 最佳实践

- 及早静音，经常静音
- 使用特定兴趣的中继
- 如果客户端支持，启用词过滤器
- 不要在没有先检查内容的情况下关注账号

## 问题："客户端崩溃" 💥

### 症状

- 应用意外关闭
- 冻结或无响应
- 加载内容时出错

### 原因与解决方案

**1. 应用过时**

- **解决方案**：从应用商店更新到最新版本
- **iOS**：App Store → 更新
- **Android**：Play Store → 管理应用

**2. 中继太多**

- **原因**：连接到 20+ 个中继压垮了客户端
- **解决方案**：减少到 4-8 个活动中继
- **优化**：使用 NIP-65 发件箱模型

**3. 缓存损坏**

- **解决方案**：清除应用数据（你不会丢失帖子/关注）
- **核选项**：重新安装应用，重新导入密钥

### 尝试不同的客户端

如果一个客户端始终有问题，尝试另一个：

| 平台           | 替代方案          |
| ------------------ | -------------------- |
| iOS（Damus）        | Nos、Nostur          |
| Android（Amethyst）| Primal 网页、Nostros  |
| 网页（Primal）       | Iris、Snort、Coracle |

## 问题："丢失了我的密钥" 🔑

### 症状

- 无法登录客户端
- 没有 nsec/npub 备份
- 密钥只在坏掉的一台设备上

### 残酷的事实

> ⚠️ **如果你没有密钥备份，你的账号无法恢复。**

这是设计如此——Nostr 没有"忘记密码"，因为没有中央服务器持有你的密钥。

### 你能做什么

**1. 搜索备份**

- 检查密码管理器
- 寻找截图
- 检查电子邮件中的欢迎消息
- 检查安装了客户端的其他设备

**2. 检查客户端是否存储了密钥**

- 一些客户端缓存密钥
- 尝试不粘贴密钥登录
- 检查浏览器扩展（Alby、Nos2x）

**3. 创建新账号**

- 生成新密钥
- 在其他平台上宣布旧账号丢失
- 开始重建你的关注

### 预防（现在就做）

1. **在纸上写下你的 nsec**
2. **存储在密码管理器中**（1Password、Bitwarden）
3. **使用签名应用**（Amber、Nos2x）避免输入 nsec
4. **在不同位置制作多个备份**

## 问题："无法连接到中继" 🔌

### 症状

- "连接失败"错误
- 中继显示为离线
- 帖子不同步

### 原因与解决方案

**1. 中继宕机**

- **测试**：在浏览器中打开中继 URL（应该显示错误或 ws 页面）
- **解决方案**：检查中继的状态页面或社交媒体
- **修复**：暂时移除，恢复时重新添加

**2. 网络问题**

- **测试**：你能访问其他网站吗？
- **解决方案**：检查互联网连接，尝试不同的网络
- **注意**：一些网络阻止 WebSocket 连接

**3. 错误的中继 URL**

- **检查**：必须以 `wss://`（安全）或 `ws://`（不安全）开头
- **常见错误**：`https://relay.com` 而不是 `wss://relay.com`
- **修复**：在设置中编辑中继 URL

**4. 中继已满**

- **原因**：一些免费中继达到容量限制
- **解决方案**：稍后再试或使用不同的中继
- **长期**：考虑付费中继

## 问题："闪电打赏无法工作" ⚡

### 症状

- 闪电打赏按钮无响应
- "支付失败"错误
- 无法发送或接收闪电打赏

### 原因与解决方案

**1. 没有连接钱包**

- **解决方案**：在客户端设置中连接闪电钱包
- **参见**：[闪电打赏指南](/zh/guides/zaps-and-lightning)

**2. 余额不足**

- **检查**：钱包余额
- **解决方案**：向钱包添加资金
- **最低**：通常需要 100+ 聪用于费用

**3. 钱包离线**

- **原因**：非托管钱包需要在线
- **解决方案**：打开你的钱包应用，确保它正在运行
- **替代方案**：使用托管钱包如 Alby

**4. 错误的闪电地址**

- **检查**：你的闪电地址在个人资料中正确吗？
- **测试**：尝试给自己发送 10 聪
- **修复**：在个人资料设置中更新地址

## 问题："图片无法加载" 🖼️

### 症状

- 图片图标损坏
- 旋转加载器
- 帖子中没有媒体

### 原因与解决方案

**1. 中继媒体限制**

- **原因**：一些中继不存储图片，只存储文本
- **解决方案**：图片托管在单独的服务器上（Blossom 等）
- **修复**：检查图片是否在网页客户端加载

**2. 图片主机宕机**

- **原因**：托管图片的服务器离线
- **测试**：尝试直接打开图片 URL
- **注意**：如果主机宕机，你无能为力

**3. 客户端设置**

- **检查**：设置 → 媒体 → "加载图片"
- **一些客户端**：有阻止图片的数据节省模式
- **修复**：在设置中启用媒体加载

**4. 连接缓慢**

- **原因**：慢速互联网上的大图片
- **解决方案**：等待加载，或切换到更快的网络
