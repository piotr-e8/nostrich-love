## Czym jest NIP-05? 🆔

NIP-05 (Nostr Implementation Possibility #5) pozwala Ci mieć czytelny identyfikator w formacie `ty@domena.pl` zamiast długiego ciągu losowych znaków.

### Problem, Który Rozwiązuje

```
Przed NIP-05:
┌──────────────────────────────────────────────┐
│ Obserwuj: npub1xxxxxxxxxxxxxxxxxxxxxxxxxxxx  │
│ "Hej, obserwuj mnie! Jestem npub1abc123..."  │
└──────────────────────────────────────────────┘
                ↓
Po NIP-05:
┌──────────────────────────────────────────────┐
│ Obserwuj: alicja@example.pl                  │
│ "Hej, obserwuj mnie! Jestem alicja@example.pl" │
└──────────────────────────────────────────────┘
```

### Co Otrzymujesz

- ✅ **Łatwe do udostępniania**: "Znajdź mnie pod bob@nostrplebs.com"
- ✅ **Wygląda profesjonalnie**: Czysty, zapadający w pamięć identyfikator
- ✅ **Sygnał zaufania**: Odznaka NIP-05 w wielu klientach
- ✅ **Łatwiejsze do znalezienia**: Szukaj według swojego identyfikatora

### Ale Pamiętaj...

> ⚠️ **NIP-05 jest opcjonalny.** Możesz doskonale używać Nostr z samym npub.

Identyfikator NIP-05 to **wygoda**, nie wymóg. Twój `npub` to Twoja prawdziwa tożsamość na Nostr.

## Dlaczego Warto Mieć NIP-05? ✨

### Łatwiejsze Do Udostępniania

```
Na imprezie:
"Jaki masz Nostr?"

Bez NIP-05:
"Eee... n-p-u-b-one-x-x-x... pozwól, że znajdę to w telefonie"

Z NIP-05:
"Po prostu alicja@example.pl"
```

### Profesjonalny Wygląd

- **Firmy**: `support@twojafirma.pl`
- **Twórcy**: `artysta@twojadomena.pl`
- **Deweloperzy**: `dev@projektopensource.pl`

### Zaufanie i Autentyczność

Wiele klientów pokazuje odznakę ✓ dla użytkowników NIP-05:

```
┌─────────────────────┐
│ 👤 Alicja ✓         │
│ alicja@example.pl   │
│ "Edukator Bitcoin"  │
└─────────────────────┘
```

To pomaga ludziom wiedzieć, że obserwują prawdziwą Ciebie, a nie oszusta.

### Czy Potrzebujesz Jeden?

**Nie.** Możesz doskonale używać Nostr bez tego.

**Ale...** jest wysoce zalecane, jeśli:

- Budujesz markę osobistą
- Tworzysz treści
- Prowadzisz biznes
- Jesteś poważnie nastawiony do Nostr na dłuższą metę
- Masz dość czytania 63-znakowych ciągów

### Nie To Centralizacja!

Niektórzy obawiają się, że NIP-05 oznacza "scentralizowaną tożsamość". Nie oznacza:

- Możesz mieć **wiele** identyfikatorów NIP-05
- Możesz je **zmieniać** w dowolnym momencie
- Twój **npub** to wciąż Twoja prawdziwa tożsamość
- NIP-05 to tylko **wskaźnik** do Twojego npub

## Używanie Własnej Domeny 🌐

Dla pełnej kontroli i profesjonalizmu, użyj własnej domeny.

### Krok 1: Kup Domenę

Każdy rejestrator domen działa:

- [Namecheap](https://namecheap.com)
- [Porkbun](https://porkbun.com)
- [Cloudflare Registrar](https://www.cloudflare.com/products/registrar/)

Koszt: Zazwyczaj $10-15/rok

### Krok 2: Utwórz plik nostr.json

Hostuj plik pod `https://twojadomena.pl/.well-known/nostr.json`:

```json
{
  "names": {
    "alicja": "b0635d6a9851d3aed0cd6c495b282167acf761729078d975fc341b22650b07b9"
  }
}
```

<Callout variant="warning" title="Użyj klucza publicznego w formacie hex, nie npub">
  NIP-05 wymaga klucza publicznego w postaci surowego hex małymi literami.
  Jeśli wkleisz `npub1...` do `nostr.json`, klienci nie zweryfikują Cię — i zrobią
  to po cichu, bez żadnego komunikatu wyjaśniającego dlaczego.

Większość klientów pokazuje postać hex w Ustawienia → Klucze, podpisaną
"public key (hex)". Możesz też wkleić swój npub do narzędzia niżej na tej
stronie, które pokazuje obie postacie obok siebie.

</Callout>

**Nie ma tu żadnych rekordów DNS.** Weryfikacja NIP-05 to zwykłe zapytanie
HTTPS do `/.well-known/nostr.json`. Nie potrzebujesz rekordu TXT, CNAME ani
żadnego innego wpisu DNS poza tym, który już kieruje Twoją domenę na serwer.

Twój identyfikator staje się: `alicja@twojadomena.pl`

### Przykładowy Przewodnik Konfiguracji

**Scenariusz:** Masz domenę `alicja.pl`

1. **Utwórz plik JSON:**

```json
{
  "names": {
    "alicja": "b0635d6a9851d3aed0cd6c495b282167acf761729078d975fc341b22650b07b9"
  }
}
```

2. **Prześlij na swój serwer:**

```
https://alicja.pl/.well-known/nostr.json
```

3. **Zweryfikuj, że działa:**
   Otwórz w przeglądarce: `https://alicja.pl/.well-known/nostr.json`

4. **Dodaj do profilu Nostr:**
   W swoim kliencie: Ustawienia → Profil → NIP-05 → `alicja@alicja.pl`

## Testowanie Twojego NIP-05 ✅

### Sprawdź Swój Identyfikator

Użyj naszego narzędzia poniżej lub odwiedź URL swojego identyfikatora:

<NIP05Checker showForm={true} client:load />

### W Twoim Kliencie

Większość klientów pokazuje status NIP-05:

**Damus/Amethyst:**

- Ustawienia → Profil → Pole NIP-05
- Pokazuje ✓, gdy skonfigurowane poprawnie

**Primal:**

- Profil pokazuje odznakę NIP-05
- Kliknij odznakę, aby zobaczyć szczegóły

### Rozwiązywanie Powszechnych Problemów

**"NIP-05 nie działa"**

- Sprawdź dwukrotnie, czy Twój npub jest poprawny w nostr.json
- Upewnij się, że JSON jest ważny (użyj walidatora JSON)
- Sprawdź, czy plik jest dostępny pod dokładnym URL

**"Plik nie znaleziony"**

- Upewnij się, że folder `.well-known` został utworzony
- Sprawdź, czy Twój serwer obsługuje ukryte katalogi
- Zweryfikuj ścieżkę: `/.well-known/nostr.json`

**"Domena nie rozwiązuje się"**

- Zmiany DNS mogą zająć do 24 godzin
- Wyczyść pamięć podręczną DNS
- Sprawdź poleceniem `dig` lub `nslookup`

**"Klient nie rozpoznaje"**

- Niektórzy klienci cache'ują wyniki wyszukiwania NIP-05
- Spróbuj się wylogować i zalogować ponownie
- Poczekaj kilka minut na propagację

**Błąd "Weryfikacja Nie Powiodła Się"**

**Możliwe przyczyny:**

1. **Błąd składni JSON** - Sprawdź brakujące cudzysłowy lub przecinki
2. **Zła lokalizacja pliku** - Musi być w `/.well-known/nostr.json`
3. **Cache'owanie** - Poczekaj 10-15 minut i spróbuj ponownie
4. **Wymagane HTTPS** - Musi być serwowane przez HTTPS

**Rozwiązanie:**

- Zwaliduj JSON na jsonlint.com
- Sprawdź czy plik jest w dokładnej ścieżce
- Wyczyść cache klienta
- Upewnij się, że certyfikat SSL jest ważny

**Błąd "Nie Znaleziono"**

**Możliwe przyczyny:**

1. Plik nie został przesłany do właściwej lokalizacji
2. Serwer blokuje katalogi z kropką
3. Zła domena

**Rozwiązanie:**

- Zweryfikuj czy plik istnieje pod dokładnym URL
- Sprawdź czy `.htaccess` lub konfiguracja serwera pozwala na katalogi z kropką
- Potwierdź, że używasz właściwej domeny

**Problemy Specyficzne dla Dostawcy**

**NostrPlebs:**

- Sprawdź folder spam dla emaila weryfikacyjnego
- Upewnij się, że npub jest poprawny (nie nsec!)
- Skontaktuj się z pomocą techniczną, jeśli utkniesz

**Samodzielny:**

- Zweryfikuj propagację DNS: `dig twojadomena.pl`
- Sprawdź logi serwera pod kątem błędów
- Upewnij się, że uprawnienia plików pozwalają na odczyt

<Callout variant="warning">
  Nigdy nie udostępniaj swojego nsec (klucza prywatnego) podczas konfiguracji NIP-05. Tylko Twój npub
  (klucz publiczny) jest potrzebny.
</Callout>

### Weryfikacja Konfiguracji

**Metoda 1: Twój Klient**

1. Dodaj NIP-05 do profilu
2. Zapisz zmiany
3. Szukaj znaczka ✓ lub odznaki "zweryfikowano"
4. Może zająć kilka minut propagacji

**Metoda 2: Eksplorator Nostr**

1. Odwiedź eksplorator Nostr jak nostr.guru
2. Wyszukaj swój NIP-05
3. Sprawdź czy rozwiązuje się do Twojego npub

**Metoda 3: Test Bezpośredni (Command Line)**

```bash
curl https://twojadomena.pl/.well-known/nostr.json
```

**Jak Wygląda Sukces:**

- ✅ Klient pokazuje odznakę weryfikacji
- ✅ Inni mogą Cię znaleźć przez Twój NIP-05
- ✅ Twój profil wyświetla czytelną nazwę

### Zagadnienia Prywatności

- NIP-05 łączy Twój npub z domeną
- To może Cię zdeanonimizować, jeśli domena ma Twoje prawdziwe dane
- Używaj darmowych dostawców dla kont pseudonimowych
- Używaj własnej domeny, gdy chcesz być zidentyfikowany
