## Szybka Ściągawka

### Terminy

- **Nostr** - Protokół zdecentralizowanych mediów społecznościowych
- **npub** - Publiczny klucz (Twoja nazwa użytkownika)
- **nsec** - Prywatny klucz (Twoje hasło)
- **Relay** - Serwer przechowujący i przekazujący wiadomości
- **Klient** - Aplikacja do używania Nostr
- **Zap** - Napiwek w Bitcoinie przez Lightning
- **NIP-05** - Czytelny identyfikator (np. ty@domena.pl)

### Komendy

```bash
# Format klucza publicznego
npub1...

# Format klucza prywatnego
nsec1...

# Format adresu relaya
wss://relay.damus.io
```
